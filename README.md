# StockLoom

Manufacturing Inventory & Order Management System — DBMS Project.

## Quick Start

This repository is currently being developed incrementally.

Before running the project, read:

1. `PROJECT_CONTEXT.md`
2. `AGENT_RULES.md`
3. `ARCHITECTURE.md`
4. `docs/HANDOFF.md`

## Development Principle

StockLoom is a DBMS project first and a CRUD application second.

Important database behavior must be implemented, tested and documented at the PostgreSQL level.

## Main Stack

- React
- Tailwind CSS
- Node.js
- Express
- PostgreSQL

## Development Workflow

```text
Plan

Test

```

## Important

Do not fabricate benchmark results or test evidence.

Do not claim concurrency safety without an actual concurrent database test.
